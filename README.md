# File Organizer

A simple command-line file organizer built with Python.

## Features

- Detect files by their extension
- Organize files into different folders
- Move images, music, videos, notes and presentations
- Create destination folders automatically
- Display the files that were found in each category
- Display the total number of files processed

## Technologies

- Python
- Git
- GitHub

## How to Run

1. Make sure Python is installed.
2. Clone this repository.
3. Open the project folder in a terminal.
4. Create a folder named `test_files`.
5. Add some files to `test_files`.
6. Run:


python main.py
